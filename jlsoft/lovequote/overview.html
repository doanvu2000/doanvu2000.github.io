🏗Architecture

UI Layer (Activity / Fragment / Custom View)

ViewModel Layer (extends BaseViewModel, launchSafe {})
    ↓ calls suspend functions
Repository Layer (ContentRepository, MoodCheckinRepository…)
    ↓ queries
DataSource Layer (Room DAO, DataStore, WorkManager)
